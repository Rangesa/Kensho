# Z3クレート v0.12 → v0.19 移行ガイド

このドキュメントは、kensho-mcpプロジェクトでz3クレートをv0.12からv0.19にアップグレードする際の主なAPI変更点をまとめたものです。

## ビルド日時
2025-12-25

## 主なAPI変更点

### 1. ライフタイムパラメータの削除

**v0.12:**
```rust
solver: Solver<'static>
var_map: HashMap<Varnode, BV<'static>>
```

**v0.19:**
```rust
solver: Solver
var_map: HashMap<Varnode, BV>
```

**影響ファイル:**
- `src/decompiler_prototype/z3_solver/mod.rs:33, 35`
- `src/decompiler_prototype/mba/z3_simplifier.rs:114, 116`

**修正箇所数:** 約6箇所

---

### 2. Context::newがプライベートに変更

**v0.12:**
```rust
let context = Context::new(&config);
```

**v0.19:**
```rust
// Context::new()はプライベートになった
// 代わりにConfig::default()やContextBuilder等を使用
```

**影響ファイル:**
- `src/decompiler_prototype/z3_solver/mod.rs:44`

**修正箇所数:** 1箇所

---

### 3. Solver::newの引数変更

**v0.12:**
```rust
Solver::new(&context)
```

**v0.19:**
```rust
Solver::new()  // 引数なし
```

**影響ファイル:**
- `src/decompiler_prototype/z3_solver/mod.rs:45`

**修正箇所数:** 1箇所

---

### 4. PcodeOpフィールド変更

**エラー内容:**
```
error[E0063]: missing field `address` in initializer of `pcode::PcodeOp`
```

`PcodeOp`構造体に新しく`address`フィールドが必要になった可能性があります。

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/cse.rs:57`
- `src/decompiler_prototype/optimizer/rules/strength_reduction.rs:95, 106, 114, 144, 154`

**修正箇所数:** 6箇所

---

### 5. OpCodeバリアント名変更

**変更1: IntNot → 削除？**
```rust
// v0.12
OpCode::IntNot

// v0.19
// IntNotは存在しない。IntXor等の別のオペコードを使用？
```

**変更2: FloatNegate → FloatNeg**
```rust
// v0.12
OpCode::FloatNegate

// v0.19
OpCode::FloatNeg
```

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/cse.rs:113, 130`

**修正箇所数:** 2箇所

---

### 6. Varnode::new_constant → Varnode::constant

**v0.12:**
```rust
Varnode::new_constant(value, size)
```

**v0.19:**
```rust
Varnode::constant(value, size)
```

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/strength_reduction.rs:93, 108, 142`

**修正箇所数:** 3箇所

---

### 7. AddressSpace::Constant → 削除

**エラー内容:**
```
error[E0599]: no variant or associated item named `Constant` found for enum `pcode::AddressSpace`
```

`AddressSpace`列挙型から`Constant`バリアントが削除された可能性があります。

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/strength_reduction.rs:173`
- `src/decompiler_prototype/optimizer/rules/induction_variable.rs:187`

**修正箇所数:** 2箇所

---

### 8. ControlFlowGraph APIの変更

**メソッド → フィールド:**
```rust
// v0.12
cfg.blocks()      // メソッド
cfg.blocks_mut()  // メソッド

// v0.19
cfg.blocks        // フィールド
// blocks_mut()は存在しない
```

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/loop_invariant.rs:71, 88, 113, 159, 174, 196`
- `src/decompiler_prototype/optimizer/advanced.rs:93`

**修正箇所数:** 7箇所

---

### 9. Goblinクレートの変更

**エラー内容:**
```rust
// v0.12
if let Some(import_data) = &pe.imports {  // pe.importsはVec型

// v0.19（推測）
// pe.importsがOption型ではなく直接Vec型になった？
```

**影響ファイル:**
- `src/decompiler_prototype/binary_loader/mod.rs:200, 212`

**修正箇所数:** 2箇所

---

### 10. その他の問題

**randクレート未追加:**
```
error[E0433]: failed to resolve: use of unresolved module or unlinked crate `rand`
```

**影響ファイル:**
- `src/decompiler_prototype/optimizer/rules/strength_reduction.rs:122`

**対処法:** `Cargo.toml`に`rand`クレートを追加

## 修正優先度

### 高優先度（コンパイルエラー）
1. ライフタイムパラメータの削除（6箇所）
2. `Context::new()` / `Solver::new()`の変更（2箇所）
3. `Varnode::new_constant` → `Varnode::constant`（3箇所）
4. `OpCode`バリアント名変更（2箇所）
5. `cfg.blocks()` → `cfg.blocks`（7箇所）
6. `PcodeOp`の`address`フィールド追加（6箇所）
7. `AddressSpace::Constant`削除対応（2箇所）

### 中優先度
8. Goblin APIの変更（2箇所）
9. randクレート追加（1箇所）

### 低優先度（警告）
- 未使用のimport削除（多数）

---

## 推定修正時間

- **コンパイルエラーの修正:** 31箇所
- **その他:** 依存関係の調査と修正

## 修正手順案

1. ライフタイムパラメータを全て削除
2. Z3のContextとSolver初期化コードを修正
3. Varnodeのメソッド名を修正
4. OpCodeバリアント名を修正
5. ControlFlowGraph APIを修正
6. PcodeOpにaddressフィールドを追加
7. AddressSpace::Constantの代替方法を調査
8. Goblin APIの変更を調査・修正
9. randクレートを追加
